# نظام حجز مواعيد عن بُعد لمركز صحي - مركز الرؤية الطبي   Vision Medical Center - Online Appointment System
مشروع ويب متكامل يهدف إلى تسهيل عملية إدارة وحجز المواعيد الطبية، مبني باتباع معايير هندسة البرمجيات الحديثة والكود النظيف (Clean Code).
 وصف المشروع (Project Overview)
يوفر النظام منصة مرنة للمرضى للبحث عن الأطباء وحجز المواعيد، كما يوفر لوحات تحكم (Dashboards) مخصصة لكل من الإدارة، الموظفين، والأطباء لضمان سير العمل بدقة واحترافية.
## المميزات الرئيسية (Features)
### واجهة المريض:
*تصفح الأقسام: اختيار القسم الطبي المطلوب.
*اختيار الطبيب: عرض قائمة الأطباء المتاحين في كل قسم.
*الحجز والدفع: إدخال بيانات المريض وإتمام عملية الدفع لتأكيد الحجز.
*إدارة الموعد: إمكانية تعديل أو تغيير موعد الحجز في حال عدم المناسبة.
### لوحات التحكم (Dashboards):
 
*المدير (Admin)إضافة، تعديل، وحذف الأطباء والموظفين .
*الموظفين (Staff)عرض قائمة الأطباء وجداول مواعيدهم لتنظيم العمل اليومي.
*الأطباء (Doctors)عرض المواعيد الخاصة بالطبيب + تحديث حالة المريض (جاري المعاينة -> تمت المعاينة -> إلغاء).
### المعايير التقنية (Technical Standards):

*اللغات البرمجية: PHP, HTML5, CSS3, JavaScript,BootStrap.

*قواعد البيانات: MySQL (عبر XAMPP).

*المنهجية: Clean Code.
